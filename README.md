## Схема расчёта (зафиксирована)
Доминирующая школа. a=день, b=месяц, c=digitSum(год), d=a+b+c, e=центр=a+b+c+d;
линия: d1=d+e, c1=c+e («вход в денежный канал»), x=d1+c1,
x1=«под сердцем»=d1+x, x2=«под долларом»=x+c1.
Редукция: сумма цифр пока >22 (НЕ вычитание 22 — школы расходятся, выбор зафиксирован).
Источник вывода: tvoyamatritsa.ru, статья «Деньги в матрице судьбы»,
их пример 21.11.1986 включён в golden-тесты как референс.

## PDF
Шрифты передаются в renderCompatibilityPdf снаружи (RenderOptions.fonts) —
в тестах системный DejaVu, в проде положи брендовые TTF (PT Serif/PT Sans)
в ассеты web. Стандартные PDF-шрифты кириллицу НЕ содержат.

## Запуск web (по мотивам первого прогона)
1. cd packages/web && rm -rf prisma/migrations  # миграции Неустойки несовместимы
2. Поднять Postgres (docker), проверить DATABASE_URL в .env — база новая
3. npx prisma migrate dev --name matrix_init && npx prisma generate
   (prisma НЕ глобальная — только через npx из packages/web)
4. yarn dev из корня
Git-гигиена: .gitignore добавлен в v9; yarn.lock КОММИТИТЬ (это не мусор),
.next/ и install-state.gz — вычистить из индекса: git rm -r --cached.
