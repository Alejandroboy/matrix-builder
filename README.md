## Схема расчёта (зафиксирована)
Доминирующая школа. a=день, b=месяц, c=digitSum(год), d=a+b+c, e=центр=a+b+c+d;
линия: d1=d+e, c1=c+e («вход в денежный канал»), x=d1+c1,
x1=«под сердцем»=d1+x, x2=«под долларом»=x+c1.
Редукция: сумма цифр пока >22 (НЕ вычитание 22 — школы расходятся, выбор зафиксирован).
Источник вывода: tvoyamatritsa.ru, статья «Деньги в матрице судьбы»,
их пример 21.11.1986 включён в golden-тесты как референс.
